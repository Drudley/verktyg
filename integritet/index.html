Integritet

Kort version: dina filer lämnar aldrig din webbläsare.

Dina filer

SIE-filer, Stripe-exporter, Revolut- och eToro-exporter, Avanza- och Nordnet-exporter och fraktsedlar som du öppnar i verktygen – och siffrorna du skriver in i 3:12-kalkylatorn – läses och bearbetas helt lokalt i din webbläsare med JavaScript. De laddas inte upp, skickas inte till någon server och sparas inte någon annanstans än där du själv sparar resultatet. Det gäller även personnummer, namn och postnummer som du fyller i för SRU-filen i K4-verktygen: de används bara för att skapa filen i din webbläsare och sparas inte.

Det som sparas i din webbläsare

Verktygen sparar dina inställningar (t.ex. kontonummer, momssats eller etikettformat) i webbläsarens lokala lagring (localStorage) så att de finns kvar nästa gång. Om en betald funktion låses upp sparas även upplåsningen där. Du kan rensa detta när som helst genom att rensa webbplatsdata i webbläsaren.

Ingen spårning

Vi använder inga cookies, ingen analys- eller annonsspårning och laddar inga skript, typsnitt eller bilder från andra webbplatser.

Värd och betalning

Webbplatsen ligger på GitHub Pages. GitHub tar emot de vanliga tekniska förfrågningarna när sidorna hämtas (t.ex. IP-adress) enligt GitHubs integritetspolicy. Om betalning aktiveras sker köpet hos Gumroad, och när du anger en licensnyckel skickas endast nyckeln och produktens id till Gumroad för kontroll – aldrig dina filer.
