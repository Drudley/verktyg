# verktyg

Static site published at https://drudley.github.io/verktyg/ (GitHub Pages, branch main, root).

Twenty-five client-side tools – SIE till Excel, Stripe till SIE, fraktsedel till etikettskrivare, gränsbelopp 3:12-kalkylator, Revolut till K4 (SRU), eToro till K4 (SRU), Källskatt tillbaka, Udbytteskat tilbage (DK), Årsräkning från kontoutdrag, Debiteringslängd för samfällighetsföreningar, Andelstal för vägförening, Arvode god man, Styrelsearvode i förening, Kontrollbalansräkning från SIE-fil, Pensionsavsättning i aktiebolag, Semesterlöneskuld i bokslutet, Bokföra skattekontot, Representation – moms och avdrag, Bokföra inköp från EU och utlandet, Utdelning i aktiebolag, Avräkning av utländsk skatt, Feriepengeforpligtelse (DK), Kapitalafkastordningen (DK), Bokföra Shopify, Bokföra lön. Files are processed in the browser only.
This repo holds the built site; third-party licences are in `etikettskrivare-fraktsedel/vendor/`.
