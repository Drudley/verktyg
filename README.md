# verktyg

Static site published at https://drudley.github.io/verktyg/ (GitHub Pages, branch main, root).

Eleven client-side tools – SIE till Excel, Stripe till SIE, fraktsedel till etikettskrivare, gränsbelopp 3:12-kalkylator, Revolut till K4 (SRU), eToro till K4 (SRU), Källskatt tillbaka, Udbytteskat tilbage (DK), Årsräkning från kontoutdrag, Debiteringslängd för samfällighetsföreningar, Andelstal för vägförening. Files are processed in the browser only.
This repo holds the built site; third-party licences are in `etikettskrivare-fraktsedel/vendor/`.
